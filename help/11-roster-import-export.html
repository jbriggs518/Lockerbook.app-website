Import and Export Your Roster

Import from a spreadsheet

Team → Import / Export Roster → Import from Spreadsheet…

  • Choose Spreadsheet File… picks a CSV file (Numbers, Excel, and Google Sheets can all export CSV), or
  • Paste: select the cells in your spreadsheet including the header row, copy, then tap Paste.

Lockerbook recognizes these columns (the names can vary):

Column Examples of header names Notes
First name First, First Name
Last name Last, Last Name, Surname
…or one name column Name, Player, Athlete "First Last" or "Last, First"
Jersey Jersey, #, No., Number Required. "07" stays "07"
Position Pos, Position GK, D, M, F, and common variations (CB, Striker…)
Grade or grad year Grade, Class, Yr, Grad Year, Class of 9–12, Fr/So/Jr/Sr, or a year like 2028
MaxPreps ID MaxPreps ID, Athlete ID Optional

Before anything changes, you'll see a preview: new players, changes to players who already have that jersey number, and rows that were skipped (with the reason). Turn off Update players with the same jersey number to add only new players.

Privacy: Lockerbook reads only the columns above. Phone numbers, emails, birthdays, and other columns are ignored and never saved.

Roster file for MaxPreps (beta)

Team → Import / Export Roster → Roster File for MaxPreps…

  1. Fix any items under Check first. MaxPreps requires a last name, a jersey number, and a grade, so add graduation years for your players.
  2. Tap Share Roster File and send it to the computer you use for MaxPreps (AirDrop or email).
  3. On MaxPreps (desktop): your team → Roster → import from a CSV file → choose the file.

If MaxPreps doesn't accept a column, download the roster template from MaxPreps' import page and email it to contact@lockerbook.app.

The file contains student names. Share it only with your coaching staff or athletic department.
